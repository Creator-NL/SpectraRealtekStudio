# Accessibility Statement for Spectra Realtek Studio

**Spectra Realtek Studio** is committed to providing an accessible, legible, and keyboard-friendly audio control console for all Windows users.

## Accessibility Features

1. **High-Contrast Spectra Dark Theme:** Uses clear visual hierarchy on deep dark surfaces (`#0B0D14` / `#121626`) with vivid, easily distinguishable accents (`#22E8FF` cyan, `#FF2BD6` magenta, `#22E87A` green) and crisp `Segoe UI` typography.
2. **Global Keyboard Hotkeys:** Key audio functions can be triggered from anywhere on the desktop or in-game without navigating menus:
   - `Ctrl+Alt+E` — Toggle 10-Band Graphic Equalizer
   - `Ctrl+Alt+N` — Cycle to Next EQ Preset
   - `Ctrl+Alt+L` — Toggle Loudness Equalization
   - `Ctrl+Alt+K` — Toggle Karaoke Voice Cancellation
3. **Full Command-Line Interface (`SpectraRealtekStudio.Cli`):** Every core status report, preset switcher, EQ/Loudness toggle, and diagnostic dump can be operated purely from a screen-reader-friendly terminal or scripted automation.
4. **Per-Monitor High-DPI Scaling & Standard WPF Controls:** Built on native Windows WPF controls with full keyboard tab traversal, tooltips on sliders and hex inputs, and crisp scaling from 100% to 300% Windows Display Scaling.

## Feedback & Issues

If you encounter any accessibility barriers while using Spectra Realtek Studio, please open a GitHub issue or contact **contact@biohazard-corp.nl**.
